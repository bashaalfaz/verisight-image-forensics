# Recruiter project explanation

DeepSight Pro is a full-stack AI image-screening platform built with React, Flask, MongoDB and a custom CNN trained from random initialization. I implemented session-based authentication with password hashing and CSRF protection, a responsive React dashboard, image upload and validation, model inference, MongoDB-backed prediction records, private image access, paginated user history and report deletion.

The inference pipeline preprocesses images to RGB 224×224, runs the custom CNN, applies a threshold selected on the validation split, and persists the prediction, class scores, model version and timestamp. Users can revisit their previous reports through authenticated API endpoints.

The model training workflow includes source/generator-group-aware splitting, duplicate checks, training-only augmentation, class weighting, early stopping, threshold selection, independent test metrics and JPEG compression evaluation. Report only measured scores generated by running the notebook on the actual dataset.
